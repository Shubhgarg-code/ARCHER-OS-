🌟 Features

Boot sequence animation with progress bar and voice narration

HUD panels: Power, Armor, Weapons

Core animation: Spinning rings like a reactor

Radar sweep with threat blips

Alert and combat mode with screen overlay and shake effect

Weapon system: Fire, switch weapons, and energy drain

Heat management system with warnings and visual feedback

Command console: AI commands recognized via text input

Voice feedback for all actions

Mobile & desktop interactive controls

Cinematic shutdown & reboot sequence


🎮 Controls
Keyboard Controls
Key / Command	Action
Click / Tap	Start boot sequence / Fire weapon (mobile)
Space	Fire currently selected weapon
W	Switch weapon
Enter (in console)	Send command in console
alert	Activate alert mode (red overlay)
normal	Deactivate alert mode
scan	Scan area (voice + log)
shutdown	Cinematic shutdown & reload page
